                By far the largest lever a channel has. Off removes the plugin branches, the streamselect selector and the alpha composite in one go and the channel becomes a slideshow with audio. A live 1080p30 channel measured 0.999x realtime with it off against 0.415x with it on — it could not keep up at all. The plugin choice is kept either way, so switching it back on restores exactly the same look.

                live — one frame

                A plugin can only be switched to instantly if it is already rendering. An FFmpeg filtergraph is fixed at launch, so every plugin in this channel's hot set draws frames whether or not it is on screen — which is exactly why hot set membership costs CPU, roughly 0.28 cores per idle branch at 720p, measured. Anything outside the hot set is staged: the channel restarts make‑before‑break, about a 1s gap.
